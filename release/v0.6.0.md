# Sonic 3 family v0.6.0 — Experimental campaigns, Mighty and Shadow

Windows x64 ZIPs and Linux x86_64 AppImages for **Sonic 3**, **Sonic 3 &
Knuckles**, and **Sonic & Knuckles**. Supply your own matching ROM; none is
included. Accepted CRC32 values are `9BC192CE`, `63522553`, and `0658F691`.

## New experimental additions (Sonic3KRecomp)

Open **Mods** to find six independent switches. All are **experimental and
off by default**; with every switch off the game is unchanged.

- **Sonic CD stages:** all 7 zones as 70 act/time variants (Present, Past,
  Good and Bad Future), with time travel, UFO stages, Time Stones, bosses and
  CD music. Select your own **Sonic CD (US)** disc image (CUE/BIN or SGCD)
  under the mod's Files; the launcher imports it in the background. **No Sega
  CD BIOS is needed.** The import currently requires Python 3.11+ and Pillow.
- **Mighty** and **Shadow:** new playable characters on Data Select, usable in
  every enabled campaign, with their own abilities and Super forms.
- **Sonic Megamix stages:** all 19 Megamix v3 acts after Sonic 3 & Knuckles.
- **Sonic 1 and Sonic 2 stages:** play both games' zones before Sonic 3.

Campaign order: Sonic 1 → Sonic 2 → Sonic CD → Sonic 3 & Knuckles → Megamix.
Mighty, Shadow and Megamix stages need your own **Sonic Megamix v3 ROM**
(CRC32 `66ECB4F4`) and a content pack converted locally with the included
`tools/`. Sonic 1/2 stages need your own Sonic 1 REV01 and Sonic 2 REV00 ROMs;
the Megamix conversion currently builds on those too. Setup guides are in the
Sonic3KRecomp package's `docs/`. No ROM, disc, BIOS or converted pack is
distributed.

Imported stages use S3K movement, abilities, HUD and saves; this is an
adaptation, not original Sonic CD gameplay. While any of these additions is
enabled, **save states, rewind and online play are unavailable**; use the
normal in-game saves. Campaign progress is kept in a separate companion file
and is retained when an addition is turned off.

## Running and upgrading

Extract the complete Windows ZIP and run its EXE. On Linux, put the AppImage
in a writable folder, make it executable (`chmod +x`), and launch it. Use
`--appimage-extract-and-run` when FUSE is unavailable. Linux targets Ubuntu
24.04 (glibc 2.39) or compatible x86_64 systems with OpenGL.

Keep `settings.ini`, `rom-*.cfg`, `*-mods.ini`, `*-stage-pack.ini`, cartridge
saves (`*.srm`) and any `*.srm.campaign` files together when upgrading. Save
states require the same build and configuration.

## Validation and limits

All six packages pass the release verifier with every addition off: attract
state/audio hashes, native and widescreen titles, all 13 attract selections,
file select, cartridge saves, Knuckles routes and the launcher. Linux gameplay
captures match Windows pixel-for-pixel with identical RAM/VRAM.

For Sonic3KRecomp, the packaged tools imported an owned Sonic CD (US) disc into
exactly the previously qualified stage and music packs, and converted owned
Sonic 1, Sonic 2 and Megamix inputs. The packaged game then started Sonic CD
as Sonic and as Mighty, Sonic 1 as Shadow, Sonic 2, and a migrated Megamix save
as Mighty & Tails; with the packs installed but switched off, it started the
original game. Earlier campaign, character and save checks are documented in
`docs/SONIC_CD_VALIDATION.md`, `docs/MEGAMIX_STAGE_PACK.md` and
`docs/SHADOW_CHARACTER.md`.

These additions are experimental and do not certify every stage, boss or
route. Earlier widescreen and gameplay limitations still apply; The Doomsday
does not show Hyper Sonic in widescreen. Compilation alone does not qualify
cross-build netplay.
