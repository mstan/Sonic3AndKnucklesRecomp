# Sonic 3 family v0.5.1 — Widescreen file select

Patch release for **Sonic 3**, **Sonic 3 & Knuckles**, and **Sonic & Knuckles**,
with Windows x64 ZIPs and Linux x86_64 AppImages. Supply your own matching ROM.

## Changes

- Data Select in Sonic 3 and Sonic 3 & Knuckles now extends its portrait
  backdrop across Adaptive and fixed widescreen views, replacing black margins.
- Extra space shows the actual neighboring save cards and their characters.
  The card strip stops at its ends instead of repeating unrelated cards.
- The expanded composition stays intact during menu fades. Native center
  pixels and selection behavior are preserved.

All v0.5.0 fixes and mods are included. Widescreen and Knuckles remain opt-in
under **Mods**; **Widescreen → Adaptive** follows the window size.

## Upgrading

Extract the complete Windows ZIP. On Linux, make the AppImage executable and
run it from a writable folder; use `--appimage-extract-and-run` without FUSE.
Linux requires Ubuntu 24.04 (glibc 2.39) or a compatible x86_64 system.

Keep `settings.ini`, `rom-*.cfg`, `*-mods.ini` and cartridge saves (`*.srm`).
Save states require the same build and configuration; use cartridge saves to
carry progress between releases.

## Validation

The file-select change was checked at native, 16:9, 32:9 and 64:9 widths,
including every card, both ends and the return-to-title fade. Across 120
captures, game RAM/VRAM stayed identical and native center pixels were retained.
Release validation covers all 13 attract selections, file-select scrolling,
mod gameplay and both packaged launchers, with Windows/Linux pixel and state
comparisons. Each package contains source/dependency metadata and licenses;
`SHA256SUMS.txt` covers all six downloads.

The experimental widescreen and gameplay limitations documented in
[v0.5.0](https://github.com/mstan/Sonic3AndKnucklesRecomp/releases/tag/v0.5.0)
still apply, including the separately tracked longer IceCap Act 1 route.
