# Sonic 3 family v0.4.0 — Knuckles & Knuckles

Windows x64 ZIPs and Linux x86_64 AppImages for all three variants:

| Game | Package prefix | Owner ROM |
| --- | --- | --- |
| Sonic 3 | Sonic3Recomp | `sonic3.bin` (2 MB) |
| Sonic 3 & Knuckles | Sonic3KRecomp | `sonic3k.bin` (4 MB combined lock-on) |
| Sonic & Knuckles | SonicAndKnucklesRecomp | `sandk.bin` (2 MB) |

Bring your own matching ROM. No ROM is included.

## Changes

- Optional **Knuckles & Knuckles** mod in the combined game and S&K: 8, 16,
  24 or 34 extra Knuckles follow the player. Controllers 2–4 can drive the
  corresponding extras. Local play only; the mod is off by default.
- S3K gets a still Knuckles portrait with complete fists, **KNUCKLES 3** and
  **Knuckles The Echidna**, plus the crowd parade. Title art is decoded from
  your ROM at runtime. S&K gets its Knuckles & Knuckles title treatment.
- Empty S3K save files and No Save initially select Knuckles while the mod is
  enabled. Existing saves retain their character; empty selections can still
  be changed before starting.
- Includes the current adaptive widescreen renderer and launcher settings.
  Enable widescreen through **Mods > Widescreen**, choosing Adaptive to fit
  the window. The Knuckles mod is under **Mods > Knuckles & Knuckles**.
- Repeatable production packaging for both platforms, with bundled runtime
  dependencies, launcher assets, license notices and source/pin metadata.

## Running and upgrading

Extract the whole Windows ZIP and run its EXE. On Linux, put the AppImage in a
writable folder, make it executable (`chmod +x`), and launch it. Add
`--appimage-extract-and-run` if FUSE is unavailable. Use the launcher ROM picker
or place the matching raw cartridge beside the application.

Preserve your `settings.ini`, `rom-*.cfg`, `*-mods.ini` and `*.srm` files when
upgrading. Keep the Windows `assets/` folder beside the EXE. Linux refreshes
its bundled assets beside the AppImage without replacing your settings/saves.

## Validation and limits

The title, caption and complete still fist passed owner review. Production
builds pass 21/21 CTests on each platform. The packages pass 18 scenarios per
platform covering launchers, native/wide titles, empty and existing saves,
Knuckles level entry, and 3600-frame attract runs. Captured gameplay pixels,
RAM/VRAM, and attract state/audio hashes match between Windows and Linux.
Windows DLL dependencies and Linux state/ROM discovery/relocation checks pass.
This is not a claim of a complete campaign playthrough.

The Knuckles crowd is for story zones; special/bonus/competition stages and
demos keep stock behavior. Some objects react only to the original players;
monitors break only for Player 1. Netplay is unavailable while this mod is on.
See the source's `docs/KNUCKLES_ARMY.md` for implementation limits.

Linux targets Ubuntu 24.04 (glibc 2.39) or compatible x86_64 systems with OpenGL.
Older distributions and Steam Deck remain unvalidated. `SHA256SUMS.txt` covers
all six packages. See the packaged README and licenses for usage and notices.
